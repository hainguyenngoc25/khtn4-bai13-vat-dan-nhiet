## Khoa học 4 – Bài 13: Vật dẫn nhiệt tốt, vật dẫn nhiệt kém

Học liệu số tương tác **Module 3 – Chống nóng, chống rét**, được phát triển trên nền tảng HTML, CSS và JavaScript theo giao diện YooBook. Học liệu giúp học sinh khám phá khả năng giữ ấm của động vật sống ở vùng lạnh và tìm hiểu các biện pháp chống nóng, chống rét trong đời sống, chăn nuôi và trồng trọt thông qua mô hình pseudo-3D, sa bàn tương tác, hiệu ứng mô phỏng truyền nhiệt, câu hỏi kiểm tra và hoạt động hình thành kiến thức trực quan.
